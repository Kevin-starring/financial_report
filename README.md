# 📊 Financial Report — 선물 시장 보고서 & 옵션 매도 신호봇

Yahoo Finance 데이터 기반으로 자동 생성되는 두 가지 보고서를 GitHub Pages로 배포합니다.

| 페이지 | 내용 |
|---|---|
| `index.html` | 글로벌 선물 시장 동향 보고서 (통화·귀금속·에너지·곡물) |
| `options.html` | **옵션 매도 신호봇** — 원자재·외환·농산물·금속·에너지 옵션 매도 기회 탐지 |

## 📡 옵션 매도 신호봇 (`options_signal_bot.py`)

직접 매매하지 않고, **옵션 매도(Sell) 관점의 기회 신호**를 추천 사유와 함께 제공합니다.

- **대상 자산 (14종)** — 옵션이 상장된 선물 추종 ETF
  - 에너지: USO(WTI 원유), UNG(천연가스)
  - 금속: GLD(금), SLV(은), CPER(구리)
  - 농산물: CORN(옥수수), WEAT(밀), SOYB(대두), DBA(농산물 바스켓)
  - 외환: FXE(유로), FXY(엔), FXA(호주달러), UUP(달러인덱스)
  - 원자재 종합: DBC
- **만기 필터** — 차월물(다음 달) ~ 차차월물(다다음 달) 만기만 추천 (세타 소멸이 효율적인 약 30~90일 구간)
- **전략 3종** — 풋매도(과매도+고변동성), 콜매도(과매수+고변동성), 양매도/스트랭글(횡보+변동성 고점)
- **신호 점수 (0~100)** — RSI(14), 볼린저밴드 %B, 변동성 랭크(1년 백분위), 추세(SMA50, 30일 등락)를 종합. 55점 이상만 표시
- **행사가 선정** — 블랙-숄즈 델타 ≤ 0.30의 OTM 행사가 중 유동성(미결제약정 ≥ 50, 매수호가 ≥ $0.05)을 충족하고 연환산 프리미엄 수익률이 가장 좋은 것
- **추천 사유** — 신호마다 어떤 지표가 왜 유리한지 한글 설명 + 리스크 경고 자동 생성

### 실행

```bash
pip install -r requirements.txt

# HTML 보고서 생성
python options_signal_bot.py --generate options.html

# 로컬 웹서버로 확인 (http://127.0.0.1:8081)
python options_signal_bot.py
```

## 📱 아이폰에서 사용하기

1. GitHub Actions가 매 평일 미국 장 마감 후(한국시간 새벽 6:10) 자동으로 보고서를 생성해 GitHub Pages에 배포합니다. `Actions → Generate Futures Report → Run workflow`로 수동 실행도 가능합니다.
2. 아이폰 Safari에서 GitHub Pages 주소의 `options.html`을 엽니다.
3. **공유 버튼 → "홈 화면에 추가"** 를 누르면 앱처럼 아이콘으로 실행됩니다 (전체화면 웹앱 지원).
