# 📊 Financial Report — 선물 시장 보고서 & 옵션 매도 신호봇

Yahoo Finance 데이터 기반으로 자동 생성되는 두 가지 보고서를 GitHub Pages로 배포합니다.

| 페이지 | 내용 |
|---|---|
| `index.html` | 글로벌 선물 시장 동향 보고서 (통화·귀금속·에너지·곡물) |
| `options.html` | **옵션 매도 신호봇** — 원자재·외환·농산물·금속·에너지 옵션 매도 기회 탐지 |

## 📡 옵션 매도 신호봇 (`options_signal_bot.py`)

직접 매매하지 않고, **옵션 매도(Sell) 관점의 기회 신호**를 추천 사유와 함께 제공합니다.

- **대상 자산 (10종)** — 시장 동향 보고서와 동일한 선물 종목 (가격 기준 일치)
  - 외환: AUD/USD(6A), USD/JPY(6J), EUR/USD(6E)
  - 금속: 금 GC, 은 SI / 에너지: WTI 원유 CL, 천연가스 NG
  - 농산물: 옥수수 ZC, 대두 ZS, 밀 ZW
- **만기 필터** — 차월물(다음 달) ~ 차차월물(다다음 달) 만기만 추천 (세타 소멸이 효율적인 약 30~90일 구간). 만기일은 셋째 금요일 기준 대표치이며 상품별 실제 만기와 다를 수 있음
- **전략 3종** — 풋매도(과매도 반등 확인+고변동성), 콜매도(과매수 꺾임 확인+고변동성), 양매도/스트랭글(횡보+변동성 고점)
- **추세장 차단** — 최근 30일 ±8% 초과 등락, 20일 이평선 ±5% 이격, 5일 신고/신저가 갱신 중, 볼린저밴드 이탈 상태면 역방향 매도 신호를 점수와 무관하게 차단. 추세 동반 고변동성은 "정당한 변동성"으로 보고 가점 축소 — 옵션 매도는 평균회귀 장세에서만 진입
- **신호 점수 (0~100)** — RSI(14), 볼린저밴드 %B, 변동성 랭크(1년 백분위), 추세(SMA50, 30일 등락)를 종합. 풋매도·양매도 55점, 콜매도는 65점 이상만 표시 (원자재 급등 꼬리 리스크 반영)
- **수수료 반영** — 왕복 수수료·슬리피지(약 $12/레그)를 포인트로 환산 차감. 비용이 프리미엄의 15% 초과 또는 순 연환산 4%(명목가 기준) 미만이면 신호 제외
- **손절 기준 표기** — 모든 신호에 수취 프리미엄 2배 도달 시 환매 청산 기준 제시
- **행사가·프리미엄 (모델 추정)** — 선물 옵션 실시간 체인은 무료 데이터로 제공되지 않으므로, 역사적 변동성(HV20)을 IV 프록시로 사용해 블랙-76 모델로 OTM 행사가(거래소 행사가 간격 정렬, 델타 풋 ≤ 0.30 / 콜 ≤ 0.25)와 프리미엄을 추정. 주문 전 HTS에서 실제 호가 확인 필요
- **추천 사유** — 신호마다 어떤 지표가 왜 유리한지 한글 설명 + 리스크 경고 자동 생성

### 실행

```bash
pip install -r requirements.txt

# HTML 보고서 생성
python options_signal_bot.py --generate options.html

# 로컬 웹서버로 확인 (http://127.0.0.1:8081)
python options_signal_bot.py
```

## 📱 아이폰에서 사용하기

1. GitHub Actions가 매 평일 미국 장 마감 후(한국시간 새벽 6:10) 자동으로 보고서를 생성해 GitHub Pages에 배포합니다. `Actions → Generate Futures Report → Run workflow`로 수동 실행도 가능합니다.
2. 아이폰 Safari에서 GitHub Pages 주소의 `options.html`을 엽니다.
3. **공유 버튼 → "홈 화면에 추가"** 를 누르면 앱처럼 아이콘으로 실행됩니다 (전체화면 웹앱 지원).
